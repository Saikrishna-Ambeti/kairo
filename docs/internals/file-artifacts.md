# File preview boundaries

Office files must use the signed binary asset route. The workspace text reader cannot
read these ZIP archives. Keeping conversion in the client avoids requiring Office
software on remote environments; downloads still return the original environment file.

Each format converts in a separate worker with a deadline. Check expanded ZIP sizes
before conversion, then display the result in a sandboxed frame. A compressed file size
limit alone does not bound the memory consumed by an Office archive.
