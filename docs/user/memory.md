# Memory

Kairo can keep useful context across threads with hosted Supermemory. You do not need a
Supermemory account, Supermemory API key, CLI, or provider plugin.

Open **Settings → Memory**, choose which provider instances may use memory, then select **Enable
memory**. Memory tools appear when those providers start a new session. Existing sessions keep the
tools they started with.

Memory is user-wide, so saved preferences and decisions can be recalled from different projects.
Kairo Cloud keeps each user's memory isolated. The Supermemory API key never enters your Kairo
server or coding-agent process.

If Settings reports that the hosted service is unavailable, Kairo cannot attach memory tools to new
provider sessions. The host operator must provide a valid Kairo Cloud grant. Other provider
features continue to work.
