# File artifacts

You can ask any connected agent to make a Word document, PowerPoint presentation, Excel workbook,
CSV, or PDF. In a chat, choose **Create file** or type `/` and select a format. On mobile, tap
**+** and select a format. Describe the file you need and attach source material if you have it.
The same actions are available with every professional profile.

Kairo asks the agent to save the result in the thread's workspace and link it in its response.
When the file is part of a completed workspace checkpoint, it appears in the thread's
**Artifacts** panel and in **Library** on web and desktop. Library search matches titles,
filenames, paths, projects, and thread names. On mobile, open **Library** from Home to search
files in an environment, or open a thread's **Files** view to find its artifacts. Tap **Open**
to save or share a copy with another app. **Create file** in Library starts a new task.

Choose **Revise** beside an artifact to open a draft in its thread. Name the page, slide,
passage, sheet, or cells and describe the change. The draft asks the agent to keep the rest of
the file intact. Review the result before relying on it.

On web and desktop, PDF artifacts open in a browser tab. Open a Word document, PowerPoint
presentation, or Excel workbook from its chat link to preview it in the sidebar. Use Download
to save the original file from the workspace. CSV files download in their original format.
File quality and supported formats depend on the selected provider and the tools available in
its environment.
